webapps

五个自己写的小工具，全部跑在浏览器里，没有后端、没有构建步骤。有些是单文件 HTML，有些是可以离线安装的 PWA。

01 / GAME

五子棋 · Gomoku

移动端优先的本地双人五子棋，支持无限悔棋、可离线安装的 PWA。棋盘与胜负逻辑纯手写，无第三方库。

PWA原生 JS离线可用
打开 → 源码
02 / MATH

LaTeX → GeoGebra

把 LaTeX 数学公式转成 GeoGebra 的代数输入格式，内置 KaTeX 实时预览，自动补全乘号等常见差异。

单文件 HTMLKaTeX教学用
打开 → 源码
03 / IMAGE

image_canvas_expander

“减数分裂”式扩边裁切：向黑底四周填充白色、让 AI 只改框内内容，再裁掉带水印的白边。

单文件 HTMLCanvasAI 生图
打开 → 源码
04 / IMAGE

Local Photo Converter

浏览器内完成极限图片压缩与格式转换，图片不上传服务端；仓库另带一个 Node 本地预览小服务。

前端压缩零上传Apache-2.0
打开 → 源码
