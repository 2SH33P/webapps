# image_canvas_expander
通过”减数分裂“的方式牺牲分辨率实现AI平台的去角落水印的单文件HTML程式。

## 原理

为了规避AI生图成品图中角落品牌水印的添加，本程式提供了一种先对一张黑色背景进行向两侧（或四周）使用白色填充，让AI仅修改黑色部分方框内的内容，再导入本程序裁剪掉含有水印的白色部分的方法。

## 如何使用

程式使用方式非常简单。

1. （可选）事先拿到一张含有品牌水印的图片，通过二分法（按下重置键可以实现对图片大小的重置）找到能保留最多内容，同时找不到水印的图片的最佳比例值，随后刷新页面（这使得图片区域清空图片，本文件在规划的时候忘记了，见谅）。
2. 在没有输入任何照片的前提下，输入你指定的比例值（可以自己估一个，不过为了分辨率损失最小推荐按照1的方法找最佳值）扩大，这个时候获得一张底图。
3. 把底图喂给AI生图工具，限制它将最终成果填充进黑白色参考图的黑色方块中。
4. 回到本程序裁剪得到成品。
